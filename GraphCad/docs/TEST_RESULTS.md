## Native application and visual checks

GraphCad was launched on the actual macOS Cocoa desktop. Light and dark interfaces, the Precision dialog, linked perpendicular example, object/property panels, regression table, branding and compact export control were captured and visually inspected. Actual screenshots are in `docs/images/`; no placeholders are used. White drawing paper and document styles remain independent of interface colors.

The System theme option uses Qt's system color-scheme detection and change notification. Light/Dark selection and persistence are tested. An actual operating-system appearance change during an open session was not physically exercised.

## Built macOS application

The existing PyInstaller build system produced `dist/GraphCad.app`, version 1.1.0, Mach-O arm64. The bundle retains `io.graphite.editor` for compatibility and displays GraphCad in Finder/application metadata. It targets macOS 14+ because of the selected dependency wheels. The app has separate dynamically loaded Qt libraries.

The final frozen application was run with `--verify-build DIRECTORY`. Its [verification report](frozen-verification.json) passed all seven checks:

1. Document-space projection, linked perpendicular updates, orientation and signed Pearson r.
2. Editable document save/reopen equality.
3. PNG decoded at exactly 1920 × 1080 pixels.
4. Identical PNG pixels after switching the interface to dark.
5. PDF generated by the bundled Qt writer.
6. SVG parsed with vector content and no embedded image element.
7. DXF reopened with geometry and a clean audit.

The final installed executable also exited successfully from `--smoke-test` on the actual Cocoa desktop. Source checks inspect PDF vector paths/text and page dimensions; the packaged PDF was additionally inspected for GraphCad creator metadata, vector content and absence of images.

## Signing and DMG

The macOS bundle is **ad hoc signed**, with no Developer ID signature or notarization. Strict deep signature verification passed. The distribution is `GraphCad-1.1.0-macOS-arm64.dmg`. Its checksum was verified using `hdiutil verify`; read-only mounting confirmed the GraphCad app, Applications shortcut and dependency notices. The contained executable was compared with the tested bundle and the image was unmounted.

This validates the development image's integrity. Apple public-release signing/notarization requires the distributor's credentials and was not performed.

## Practical limitations

- Perpendiculars use supporting infinite lines for finite targets. Linked helpers are locked until detached. A temporarily directionless target retains its last valid helpers; a deleted dependency freezes/detaches them.
- Point-to-line snapping applies to point creation and a single point being dragged. Moving a multi-object group preserves its relative geometry rather than independently projecting every member.
- Ordinary orientation constraints are tool state, not persisted geometric dependency equations. Parallel/perpendicular references that become unavailable reset explicitly to Free angle.
- Earlier Graphite readers can reject new optional document fields; GraphCad loads the old v1 files and retains the `.graphite` format identifier.
- Numerical intersections and function sampling have finite resolution. Symbolic calculus, hierarchical layers, polynomial regression, LaTeX layout and independent spline tangent handles remain outside this release.
- Very large data tables/document limits and every possible aspect ratio/font/CAD viewer were not exhaustively benchmarked. Labels far outside a selected export region require adjusted bounds/margins.
